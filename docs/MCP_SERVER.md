# Knowledge Forge MCP Server

> Status: v0.1 MVP
> Updated: 2026-06-10

Knowledge Forge now includes a stdio MCP server so Claude, Cursor, OpenClaw, and other MCP-compatible agents can call Forge capabilities directly.

## Start

```powershell
npm run mcp
```

Equivalent command:

```powershell
node apps/mcp/server.js
```

## MCP Tools

### `ingest_document`

Ingest a local file into the configured vault inbox.

Current supported formats:

- `.pdf`
- `.docx`
- `.pptx` basic text extraction from slide XML
- `.xlsx` / `.xls`
- `.csv`
- `.md` / `.markdown`
- `.txt`

Returns:

- generated inbox note path
- manifest path
- agent pack path
- parser name
- summary / keyword analysis
- link and concept candidates

### `list_recent_inbox`

List recent Markdown notes under `vault/inbox`.

### `search_vault`

Lightweight local keyword search over Markdown notes.

This is not yet semantic vector search. Future versions should support embeddings and reranking.

### `create_obsidian_note`

Create a Markdown note in the vault. Defaults to `inbox/` to avoid polluting permanent knowledge structure.

### `generate_exam_review`

Generate a rules-based exam review draft from a note or direct text.

This is a local fallback. Formal learning output should later be generated by an Agent/LLM over the full source pack.

### `generate_flashcards`

Generate simple Q/A flashcards from a note or direct text.

### `generate_quiz`

Generate a simple short-answer quiz from a note or direct text.

### `link_concepts`

Return graph summary, top tags, and high-degree nodes from the vault.

### `rollback_ingestion`

Move generated ingestion artifacts into `.knowledge-forge/trash/` instead of deleting them.

## Example MCP Client Config

Exact config shape depends on the client. Typical stdio config:

```json
{
  "mcpServers": {
    "knowledge-forge": {
      "command": "node",
      "args": ["E:/创作工坊/Knowledge-Forge/apps/mcp/server.js"],
      "env": {
        "KF_VAULT_PATH": "E:/创作工坊/知识库/LLM-Wiki"
      }
    }
  }
}
```

## Design Notes

- The server intentionally exposes local-first operations only.
- Generated notes go to inbox by default.
- `rollback_ingestion` is recoverable: it moves files to trash instead of deleting.
- Current generation tools are rule-based MVPs, not final AI outputs.
- PPTX support is basic: it extracts text from `ppt/slides/slide*.xml`; images, layout, speaker notes, charts and embedded media are future work.
