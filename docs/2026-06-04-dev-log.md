## 2026-06-04 19:35-19:45 MVP 完整度增强

### 本轮新增

- 后端新增规则版 summarizer / profiler（不接外部模型、不需要 key）：
  - 文档：抽取摘要句、关键词、候选标签、Markdown 大纲、基础统计。
  - Excel：生成 sheet/行数/字段数/业务类型摘要，并保留 `providerSlot` 作为未来 DeepSeek / 本地模型接口位。
- PDF 摄入从纯占位升级为轻量解析优先：
  - 优先调用已安装的 `@opendocsg/pdf2md` 生成 Markdown。
  - 解析失败、空文本或扫描件时自动回退 `pdf-placeholder`，UI 明确提示后续可接 marker / MinerU / PyMuPDF。
- Excel 字段映射增强：
  - `sourceHeader -> targetField` 现在会识别姓名、工号、部门、基础工资、绩效、扣款、应发/实发、出勤天数、考勤、药品名称、规格、批号、有效期、库存、入库/出库、供应商、金额等。
  - 字段增加 `targetField`、`confidence`、更细的 `money/date/number/text` 类型推断。
- Obsidian 笔记内容增强：
  - 文档笔记写入「规则摘要」「Markdown 大纲」「关键概念候选」「双链候选」「原始内容」。
  - Excel 笔记写入「数据摄入摘要」「字段映射表」「前 5 行数据预览」「导入提醒」。
  - manifest 记录 `analysis`，便于后续 review / rollback / LLM 二次处理。
- Web Review 页面增强：
  - 显示规则摘要、关键词、未来 AI 接口位、frontmatter 预览、保存路径。
  - 文档显示 Markdown 预览，不再只看 JSON。
  - Excel 显示字段映射预览、目标字段、置信度、前 10 行 JSON 数据预览。
  - 双链候选、概念候选保持可视化卡片，原始 JSON 仍可折叠查看。
