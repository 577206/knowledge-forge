NotebookLM 手动模式推荐流程

稳定优先：Google 页面由用户自己操作，Knowledge Forge 负责捕捉与沉淀
1. 打开 NotebookLM

点击连接按钮或访问 notebooklm.google.com，用普通 Chrome 完成登录。

2. 上传资料 / 创建 Notebook

用户在 NotebookLM 里手动上传 PDF、网页或课程资料，避免自动化登录风险。

3. 生成输出

在 NotebookLM 里生成摘要、学习指南、常见问答、测验题、音频概览等。

4. 回到 Knowledge Forge

粘贴 notebook/source 链接或结果文本，后续由 Python bridge 捕捉并写入 Obsidian。

1. 选择要记录的 NotebookLM 输出类型

这些选项不会自动替你操作 Google。当前稳定模式是：你在 NotebookLM 里生成内容，Forge 负责把结果整理、登记并写回 Obsidian。

2. 粘贴 NotebookLM 输出

在 NotebookLM 生成摘要、学习指南、常见问答或闪卡后，复制结果粘贴到这里，一键写入 Obsidian inbox。

3. 当前功能状态

  1. 已可用：检查 notebooklm-py / 登录态。
  2. 已可用：打开 NotebookLM 登录入口。
  3. 已可用：粘贴 NotebookLM 输出并写入 Obsidian inbox。
  4. 已可用：写入示例记录，测试 Obsidian 回写链路。
  5. 暂不做全自动：自动上传 source / 自动创建 notebook / 自动读取 Google 结果，先保持手动确认，避免登录态和隐私风险。
